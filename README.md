A Nature Scavenger hunt
  A check list with fun things that would've been better if the achievements worked. A clock that shows your current time wherever you are and some nice images that can help you get excited for what you'll see during this hunt.I made the items off of what I used to look for back in elementary school so it's not like absurd but still fun. The check boxes were pretty easy since i made the first box then copied the format then changed the text and the value. 
How it works: Literally just like a checklist, click the box and it marks it off.
